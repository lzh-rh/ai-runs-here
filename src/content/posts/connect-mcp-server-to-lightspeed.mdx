## What you will learn

This draft outlines how a future MCP-to-Lightspeed lab could be recorded. It has not been run in a lab environment.

> This draft does not connect an MCP server or perform a Lightspeed query. Its commands are preliminary environment checks, not a verified procedure.

## Prerequisites

Confirm that `oc whoami` returns the expected user and that you are working in the intended cluster context.

```bash
oc whoami
oc project
```

## Inspect the workload

List the workloads in the namespace used by your experiment.

```bash
oc get pods -n redhat-ods-applications
```

## What remains to be tested

Before publication, this draft needs a real MCP connection, a Lightspeed query, captured output, and the exact product and platform versions from that run.

## Troubleshooting

When the lab is run, preserve the first concrete error before changing the environment. Add troubleshooting steps only after they are exercised against that evidence.
